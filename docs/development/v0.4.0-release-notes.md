# pds-meridian v0.4.0 release notes

## Teacher reporting

Meridian v0.4.0 adds a complete, local-first reporting suite to the normal
`9. Reports` teacher workflow. Teachers can answer eight practical questions:

1. What do I need to update in my gradebook?
2. Why does this student have this grade?
3. How is my class doing on each standard?
4. How has this student progressed?
5. Who needs more evidence?
6. What changed since our last checkpoint?
7. Am I ready to close the marking period?
8. What did this assignment or assessment contribute?

Each workflow discovers canonical current class, marking-period, roster,
Grade Item, ReportingSnapshot, and mapping choices; confirms the context;
generates a bounded read-only preview; and can save a verified local JSON,
Markdown, CSV, or TSV copy without replacing an existing file. Reports never
post grades or synchronize with an SIS. External-gradebook reconciliation is
SIS-agnostic and uses an explicit teacher-authored mapping bound to the exact
proficiency scale.

## Reader compatibility

manifest capability, while exact installed producer versions remain part of
projection and cache provenance. Invalid or unsupported explicit metadata
fails closed. Metadata-absent legacy fallback remains bounded to the previously
qualified exact readers.
