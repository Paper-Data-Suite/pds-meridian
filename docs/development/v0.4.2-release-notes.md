# Meridian v0.4.2 release notes - published and verified

**Release:** [v0.4.2](https://github.com/Paper-Data-Suite/pds-meridian/releases/tag/v0.4.2)
**Status:** Published from the qualified merged source, with all six installed matrices and eight CI jobs passed. Independently downloaded wheel and sdist match the published SHA-256 digests. Physical Windows ARM64 / OneDrive classroom acceptance has not yet been performed.

## Security correction

A student-restricted grant cannot authorize an unrestricted all-student publication request. Teachers must explicitly establish legitimate protected evidence access. Missing, denied, withdrawn, mismatched, or unavailable access is represented truthfully, with bounded recovery guidance; no permissive production policy is introduced. v0.4.1 has the affected student-scope behavior: use **v0.4.2** for this correction.

## Teacher evidence journeys

Meridian discovers supported Core publications from ScoreForm, Quillan, and Concord, validates installed reader contracts and precise protected scopes, and presents native evidence through the teacher workflow. Shared Concord evidence stays distinct from individual-student evidence. Missing or unassessed does not become a fabricated proficiency or numerical score.

## Report 9 and instructional response

Teachers can analyze current Grade Item evidence without creating a ReportingSnapshot. Native ScoreForm question observations and applicable Quillan/Concord standards evidence inform a bounded report. Configured proficiency levels are reused without silently adding categories; optional planning groups are not authoritative proficiency assignments. Teachers can save interpretation, interventions, and reassessment in append-only revisions, reopen notes, and create a four-section local Markdown report. No SIS or LMS write is implied, and no intervention effect is claimed causally.
