# pds-meridian v0.3.0 release notes

## Release summary

Meridian v0.3.0 completes the first teacher-controlled Grade and reporting
release on top of the v0.2 evidence-policy, standards-proficiency, explanation,
attention, and planning foundation.

The release keeps producer-owned academic evidence, Meridian-owned policy and
calculation state, teacher decisions, local report artifacts, and official
school-system authority separate. Meridian calculates and explains advisory
Grades and produces explicit local report exports; it does not silently select
newest evidence, mutate producer source records, write directly to an SIS/LMS,
or claim that an external system accepted an export.

Package summary:

```text
Teacher-controlled evidence, proficiency, Grades, reporting, and planning for Paper Data Suite
```

The release adds the complete v0.3 Grade/report authority chain:

- immutable versioned Grade policies with explicit Academic Period activation;
- conventional points/percentage Grade calculation;
- weighted standards-based Grade calculation;
- profile-constrained standards Grade calculation;
- bounded hybrid Grade calculation over exact unrounded components;
- immutable teacher Grade overrides bound to exact source Grade revisions;
- deterministic current and historical Grade explanations;
- teacher-facing Grade/report previews;
- immutable ReportingSnapshots with separate explicit current-use selection;
- immutable Export Profiles and deterministic CSV/TSV previews;
- explicit local file or copyable-text export commit with final revalidation;
- immutable ExportReceipts that prove local export provenance only;
- Grade/report attention summaries through the Core v1 operations boundary;
- structural read-only Meridian readiness for Paper Data Suite;
- bounded canonical Meridian-owned storage keys and deep-path qualification; and
- permanent six-matrix installed qualification across Core and producer-reader
  presence/absence boundaries.

## Release invariants

v0.3.0 preserves the following audited invariants:

- unknown, unavailable, excluded, missing, incomplete, and zero remain distinct;
- zero is produced only by explicit policy semantics;
- attempt, reassessment, result, override, snapshot, and export-profile
  currentness require explicit authority rather than newest/highest inference;
- historical explanation reloads exact immutable policy, activation, result,
  and provenance references;
- Grade-affecting arithmetic is Decimal-only and isolated from ambient Decimal
  precision;
- policy rounding occurs only at the final presentation boundary;
- exclusions renormalize denominators/weights only where policy explicitly says
  they do;
- there is no universal 0-100 clamp;
- protected evidence bytes are authorization-gated;
- producer-owned source records and manifests remain producer-owned and
  unmodified;
- ReportingSnapshots retain exact projection identity rather than copying
  producer-private payloads;
- roster-backed report exports copy only selected students and selected fields;
- export approval binds exact preview bytes and commit revalidates immediately
  before delivery;
- local ExportReceipts do not assert SIS/LMS/district-gradebook acceptance;
- Core readiness and attention projections are read-only;
- owner-action identifiers remain inert routing identity; and
- Meridian's runtime dependency direction remains Core-only with exact optional
  producer readers.

## Audit and qualification

Issue #61 completed the skeptical v0.3 substantive audit with zero open substantive blockers.

Three non-blocking release corrections were discovered and resolved before
release preparation:

1. ScoreForm/Quillan current qualification had lagged the latest compatible
   stable reader releases.
2. Two current Issue #96 Quillan release-authority guards still named the older
   reader release after the qualification boundary advanced.
3. Conventional Grade arithmetic inherited the caller's ambient Decimal
   precision; v0.3 now establishes a deterministic local Decimal context.

The mandatory final nine-repository stable-release inventory was repeated on
2026-10-06 and found no newer stable direct dependency/producer release.

The promoted candidate must still pass Meridian's authoritative repository
validator against the exact authenticated Core, ScoreForm, Quillan, and Concord
release wheels before tag/publication authorization.
