## Repository-only audit boundary

This audit is deliberately repository-only and must not be included in the
source distribution.

The final audit eventually records source lineage and final artifact hashes.
Embedding those hashes in an sdist that itself contained this file would create
a self-referential artifact. The existing v0.2.0 release process established
the same boundary.

Therefore:

```text
docs/development/v0.3.0-release-audit.md
    = repository-only release record
    != source-distribution payload
```

`MANIFEST.in` excludes this file, while `scripts/check_documentation.py`
continues to require it in the repository and `scripts/check_sdist.py` fails
closed if it appears in a built sdist.
