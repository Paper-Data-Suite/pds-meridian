# pds-meridian v0.3.1 release notes

## Release summary

Meridian v0.3.1 is a bounded compatibility patch that qualifies the exact
released ScoreForm 0.12.1 public reader. It does not change Meridian's Grade,
proficiency, attempt-selection, currentness, reporting, or authority semantics.

ScoreForm 0.12.1 corrects validation of durable Standards identities in the
existing `scoreform_academic_result_manifest_v1` contract. Meridian now accepts
punctuation-bearing `standards_profile_id` and `question.standard_ids[]` values
through the existing adapter, preserves them exactly, and retains the Profile
identity as producer-native provenance.

## Compatibility qualification

Installed qualification includes the real ScoreForm 0.12.1 public reader and a
canonical v1 manifest containing:

```text
standards_profile_id: english12.njsls.2023
standard_ids:
  njsls-ela.TS.11-12.4
  njsls-ela.NW.11-12.3.D
  njsls-ela:RL.TS.11-12.4
  njsls-ela:W.NW.11-12.3.D
```

The acceptance proves exact identity preservation, canonical source-byte
immutability, retention of every attempt, unevaluated evidence eligibility, and
absence of inferred proficiency, mastery, newest/highest/best/official evidence,
currentness, or Grade authority.

The existing six installed qualification matrices remain unchanged:

```text
core
scoreform
quillan
concord
scoreform-quillan
all-adapters
```

Core remains Meridian's only unconditional runtime dependency. ScoreForm remains
an exact optional dependency and is imported lazily only for projection.
