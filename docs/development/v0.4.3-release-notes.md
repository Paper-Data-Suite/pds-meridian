# Meridian v0.4.3 — release candidate (not published)

**Status:** Proposed versioned candidate. The latest verified GitHub release remains
[v0.4.2](https://github.com/Paper-Data-Suite/pds-meridian/releases/tag/v0.4.2).
No v0.4.3 tag, signed artifact, official wheel digest, or publication is
asserted by this document. The release decision follows complete validation,
review, exact-SHA CI, and independent release-asset verification.

## Teacher workflows included in the candidate

- **#123 — teacher-first navigation:** Named, contextual teacher menus and
  explanations simplify existing Meridian navigation without new academic
  authority, silent writes, or changed Core ownership.
- **#124 — assessment discovery and Grade Item setup:** Teachers can find
  current supported assessments, establish a Grade Item relationship, and
  review exact Core and Meridian state before committing membership.
- **#125 — assessment-level eligibility:** The bounded current-assessment
  roster review and explicit Include/Exclude decisions reuse canonical
  policy, membership, and receipt protections. Missing or stale inputs fail
  closed rather than treating absence as a zero or a Grade.
- **#126 — verified corrections, attempts, and reassessments:** Distinguishes
  teacher-reviewed correction from a separate sitting, preserves immutable
  #30/#31 decisions and source history, requires teacher confirmation, and
  supports original-receipt-only recovery of an interrupted #31 selection.
  No highest/latest attempt is silently selected and no score, Standard,
  proficiency, Grade, SIS or LMS posting is inferred or automatically written.

## Qualification achieved before this version migration

A locally built, **unpublished, noneditable** Meridian package carrying the
merged November 23 source was tested with an isolated 29-student/six-question
**synthetic** ScoreForm fixture, a saved synthetic teacher profile, and exact
Core/producer dependencies. The Finding 4 prompt and genuine-retake exercise
was accepted as **PASS_WITH_TRANSCRIPT_LIMITATION**: the original session
transcript omitted four prompt strings; operator approval and a separate
cancel-only installed-menu replay independently verified them. The recovered
retake selected Attempt 2 over Attempt 1, with one #30 and one #31 revision
and two original receipts. A separately injected process termination after
writing the #31 revision and before current-selection CAS resumed the original
receipt only; fresh-process readback reported **PASS** without duplicate
decisions, receipts, or changed ScoreForm source bytes.

Those results support the original installed candidate, **not** a released
v0.4.3 wheel. An intentional process termination does not certify sudden
physical power loss or transactional atomicity across repositories.
