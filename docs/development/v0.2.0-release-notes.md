# pds-meridian v0.2.0 release notes

## Scope

Meridian v0.2.0 is the first release of the teacher-controlled academic
interpretation, standards-proficiency, and planning-signal workflow built on
the v0.1.1 publication-ingestion foundation.

The release keeps producer evidence, teacher interpretation, proficiency,
planning signals, and downstream grouping state as separate authorities.

## Fairness and semantic safeguards

v0.2.0 preserves these release invariants:

- no evidence is not zero proficiency;
- missing or insufficient evidence is not the lowest proficiency level;
- non-score producer states are not converted to numeric zero;
- producer-native values are interpreted only through exact source signatures;
- Grade Item and Academic Period aggregation use declared proficiency-scale
  positions rather than lexical IDs or hidden percentages;
- grouping bands are teacher-defined criterion-relative partitions, not
  percentile, quantile, equal-population, or class-relative bands;
- the same proficiency level maps to the same contextual band under one policy;
  and
- a missing/noncontributing planning signal never becomes the lowest band.

Planning bands are contextual ordinal instructional-planning signals. They are
not Grades, percentages, proficiency labels, ability labels, readiness labels,
disability labels, behavior labels, demographic traits, or permanent student
characteristics.

## Privacy and authorization

Protected producer projection bytes remain behind Meridian's deployment
authorization boundary. Base proficiency explanations and Core-facing
attention do not open protected evidence.

The exported Core grouping signal is intentionally minimal. Rich Meridian
academic provenance remains Meridian-local; raw grades, percentages, point
totals, producer-native ratings, Grade Item internals, attempts, reassessment,
mapping policy bodies, teacher rationale, explanations, and local paths are not
copied into the shared Core signal.

Preview, diagnostics, review, and explanation are read-only. No Core grouping
signal is written before explicit export, and export performs a final live
eligibility/currentness revalidation.

## Deliberate v0.2.0 non-goals

v0.2.0 does not implement:

- conventional, standards-based-reporting, or hybrid Grade calculation;
- Grade weighting/rounding/missing-work policy execution;
- teacher Grade/proficiency overrides;
- immutable reporting snapshots;
- report cards, SIS exports, report subscriptions, or delivery;
- Concord GroupPlan, Group, or GroupMembership creation; or
- institutional authentication/authorization policy.

Those Grade/override/reporting responsibilities remain later work, beginning
with the v0.3 boundary.
