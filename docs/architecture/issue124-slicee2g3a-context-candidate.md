# #124 E2G3A — Read-only durable context candidate discovery

The existing E2B correlation records contain reviewed-intent and original action fingerprints, not the complete original `AssessmentSetupPreview`. E2G3A discovers a unique class/work/actor-matching correlation in a strict read-only inventory with a second-read stability check.

The resulting intent digest is **not** a reconstructible preview, teacher confirmation, permission to call `RESUME`, or academic authority. Absent/ambiguous/moving evidence fails closed. The original verified preview, actor and independent canonical #122 checks remain mandatory. This is an incremental discovery primitive; teacher menu routing and durable review reconstruction are intentionally excluded.
