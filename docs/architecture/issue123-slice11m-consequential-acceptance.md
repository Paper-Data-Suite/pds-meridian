## Exactly what this script proves

In one new five-wheel Python environment, from an outside working directory, the test invokes the existing #55 installed fixture to build **real configured, provenance-complete hybrid Grade evidence** (ScoreForm/Quillan input, reported 96.00 hybrid result) and freeze its ReportingSnapshot. It then exercises the actual ordinary **named Grade review** with the same authorization-backed evidence provider, using a verified class, period and roster student rather than entering canonical IDs. The installed #56 fixture **reuses that same workspace and frozen snapshot** to create snapshot-only and roster-backed local exports, verify exact payload bytes, and reload immutable ExportReceipts.

One retained `TeacherNavigationContext` also exercises the actual named frozen snapshot and export receipt browsers. To reach the named local delivery controller, the fixture explicitly selects an immutable, already-authored Export Profile (separate from creating it). It first cancels a completed real preview at the typed confirmation boundary and verifies no academic file changed. It then types `EXPORT` and runs the real production named export controller to create a distinct file and immutable receipt, verifying the receipt and ensuring the path is not stored in it. All three exports are **local**: no SIS, LMS, Genesis, or other district gradebook posting occurs.

The installed negative checks inject an alternate, genuinely built export preview immediately before the lower-level commit to verify `ReportExportCurrentnessConflictError` and the absence of an artifact/receipt; they also inject a private-token permission denial into a valid named Grade path and verify safe, non-disclosing failure with unchanged academic files. The stale-preview and denial checks are **injected races/denials**, not a full live revoked-publication workflow. No real student records are read; fixture writes occur only under the new temporary synthetic root.
