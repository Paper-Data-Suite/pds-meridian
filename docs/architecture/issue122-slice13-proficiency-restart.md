# #122 Slice 13 — Exact proficiency-result selection after restart

This slice introduces a selection-only restart adapter for the ordinary **single-source** guided proficiency result. The action receipt is not a source of academic truth or evidence-read authorization.

A class-scoped, bounded, hardened reader enumerates canonical proficiency result identities from immutable revision 1 and verifies each hashed directory key. A current roster and the receipt's student/Standard identity fingerprint identify exactly one target; changed or ambiguous identity fails closed. The stored revision, digest, actor profile fingerprint, academic period, current Grade Item and included membership, work registration, calculation policy, and proficiency scale must all match.

A fresh authorized existing projection is obtained through Meridian's current cache-read authorization boundary; no publication, cache, or student evidence is created. The originally persisted **single** evidence input source and optional mapping profile are used to rebuild exact bounded calculation inputs and the pure outcome. A required nondefault attempt context or another unrecoverable binding cannot be guessed: any mismatch blocks resume and leaves the result unselected. Unsupported multiple/zero-source histories remain inspection-only.

The original result history and compare-and-swap baseline are checked. On explicit `RESUME`, the canonical result selector calls an optional currentness validator **under its selection lock** before publishing the target pointer. This hook is optional and leaves existing advanced selectors unchanged. No immutable writer is exposed by the restart adapter. On verification failure, the menu reports an indeterminate or unavailable operation, not a successful grade.

This slice is not a cross-record transaction, does not guarantee recovery of all historical calculations, and does not alter any producer-owned evidence or authorization grants. Qualified installed-wheel, package, cross-platform, full-suite, and CI acceptance are separate final gates.
